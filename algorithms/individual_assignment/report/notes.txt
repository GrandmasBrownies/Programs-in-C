Boyer-Moore complexity analasys

The Boyer-Moore algorithm was tested inside Visual Studio Code by counting every comparison made, which is shown by the OP counter (comparison counter).
In this implementation I choce to end the algorithm if it found the pattern and that is why in the user-interface you can choce where that pattern should be in the text.
If this would not be implemented and the pattern was placed randomly in the text, then the results of the op counter would be just as random and alot harder to compare.
It is worth mentioning that if the algorithm was made to count to the end of the text instead to find all (if any) pattern occurences.
The program would have the same OP count if the pattern was placed at the same spot but for the algorithm that stops when it finds the pattern.
That is why I have chosen to not compare text lengths for my implementation and instead where the pattern is placed in the text.
